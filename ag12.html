เพลี้ยไฟ

แมลงศัตรูพืช · พืชผัก / ไม้ดอก

สังเกตอาการ

ใบ ดอก หรือผลมีรอยสีเงิน ยอดอ่อนอาจหงิกงอหรือผิดรูป ควรตรวจหาแมลงร่วมกับอาการที่พบ

ดูแลเบื้องต้นอย่างไร

  • สำรวจยอดอ่อน ดอก และใต้ใบ
  • เคาะใบเหนือกระดาษสีขาวเพื่อดูแมลง
  • รักษาแมลงศัตรูธรรมชาติ

ลดโอกาสเกิดซ้ำ

ดูแลพืชให้แข็งแรง ไม่ให้ปุ๋ยไนโตรเจนมากเกินไป และติดตามอาการที่ยอดอ่อนอย่างสม่ำเสมอ

แมลงหวี่ขาว

แมลงศัตรูพืช · พืชผัก / ไม้ประดับ

สังเกตอาการ

พบแมลงสีขาวเล็ก ๆ เกาะใต้ใบ เมื่อรบกวนจะบินขึ้น อาจพบใบเหลือง มูลหวาน หรือราดำ

ดูแลเบื้องต้นอย่างไร

  • พลิกดูใต้ใบเพื่อสำรวจตัวอ่อนและตัวเต็มวัย
  • ตรวจต้นใกล้เคียงเพื่อดูการกระจายของแมลง
  • รักษาแมลงศัตรูธรรมชาติและแตนเบียน

ลดโอกาสเกิดซ้ำ

ตรวจต้นกล้าก่อนนำเข้าแปลง ใช้กับดักกาวเหนียวสีเหลืองเพื่อติดตามแมลง และหลีกเลี่ยงการใช้สารโดยไม่จำเป็น

อ่านเพิ่มเติม: UC IPM ↗

โรคใบจุด

โรคพืช · อาการแตกต่างตามชนิดพืช

สังเกตอาการ

ใบมีจุดสีผิดปกติ เช่น สีน้ำตาลหรือดำ จุดอาจขยายและรวมกันเป็นแผล ใบจุดมีได้หลายสาเหตุ จึงควรตรวจชนิดพืชร่วมด้วย

ดูแลเบื้องต้นอย่างไร

  • กรณีโรคจากเชื้อรา ควรลดน้ำกระเด็นระหว่างต้น
  • ทำความสะอาดอุปกรณ์ที่สัมผัสต้นเป็นโรค
  • แยกส่วนที่เป็นโรคออกอย่างเหมาะสม

ลดโอกาสเกิดซ้ำ

ใช้ต้นพันธุ์ปลอดโรค ดูแลความสะอาดของภาชนะปลูก และหลีกเลี่ยงการให้น้ำพ่นเหนือใบ

ภาพและอาการใช้เพื่อสังเกตเบื้องต้น ไม่สามารถยืนยันเชื้อสาเหตุได้จากรูปเพียงอย่างเดียว

อ่านเพิ่มเติม: UC IPM ↗

หนอนชอนใบ

แมลงศัตรูพืช · มะเขือเทศ / ผักตระกูลกะหล่ำ

สังเกตอาการ

ใบมีรอยเส้นคดเคี้ยวสีอ่อน เกิดจากตัวอ่อนกินอยู่ภายในเนื้อใบ รอยเก่าอาจยังอยู่แม้ตัวอ่อนออกไปแล้ว

ดูแลเบื้องต้นอย่างไร

  • ตรวจรอยใหม่ว่ามีตัวอ่อนอยู่หรือไม่
  • ติดตามความเสียหายร่วมกับอายุของพืช
  • อนุรักษ์แตนเบียนซึ่งช่วยควบคุมแมลงตามธรรมชาติ

ลดโอกาสเกิดซ้ำ

สำรวจแปลงสม่ำเสมอ และหลีกเลี่ยงการใช้สารกำจัดแมลงแบบครอบคลุม โดยไม่จำเป็น เพราะอาจกระทบศัตรูธรรมชาติ

อ่านเพิ่มเติม: UC IPM ↗

โรคใบไหม้

โรคพืช · ตรวจชนิดพืชและสาเหตุร่วมกัน

สังเกตอาการ

แผลบนใบขยายรวมกันเป็นบริเวณกว้าง ใบเปลี่ยนเป็นสีน้ำตาลหรือดำ ใบไหม้เป็นลักษณะอาการ ไม่ใช่ชื่อเชื้อเพียงชนิดเดียว

ดูแลเบื้องต้นอย่างไร

  • แยกต้นที่มีอาการและสำรวจต้นใกล้เคียง
  • กรณีโรคจากแบคทีเรีย ควรลดน้ำกระเด็น
  • ทำความสะอาดมือและอุปกรณ์หลังสัมผัสต้นเป็นโรค

ลดโอกาสเกิดซ้ำ

เลือกวัสดุขยายพันธุ์ที่ปลอดโรค ดูแลความสะอาดของพื้นที่ปลูก และหลีกเลี่ยงการให้น้ำพ่นเหนือใบ

หากไม่แน่ใจสาเหตุ ควรถ่ายภาพทั้งต้นและส่วนที่เสียหาย เพื่อปรึกษาเจ้าหน้าที่เกษตร

อ่านเพิ่มเติม: UC IPM ↗

หนอนใยผัก

แมลงศัตรูพืช · คะน้า / กะหล่ำ / ผักกาด

สังเกตอาการ

หนอนกัดกินใต้ใบจนบางใสหรือเป็นรู เมื่อถูกรบกวนอาจดิ้นและทิ้งตัวด้วยเส้นใย

ดูแลเบื้องต้นอย่างไร

  • สำรวจใต้ใบและใบอ่อน
  • แปลงขนาดเล็กสามารถเก็บหนอนออกเมื่อพบ
  • รักษาแตนเบียนและศัตรูธรรมชาติ

ลดโอกาสเกิดซ้ำ

ตรวจต้นกล้าก่อนปลูก และใช้ตาข่ายป้องกันแมลงที่เหมาะสม ไม่ควรใช้สารเดิมซ้ำโดยไม่มีคำแนะนำ เพราะหนอนใยผักมีปัญหาการดื้อสาร
